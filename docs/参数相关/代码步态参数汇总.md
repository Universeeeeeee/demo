# 步态分析参数与项目代码映射汇总表

根据 `optojump参数汇总.md` 中的理论定义，与当前项目代码（主要集中在 `Gait_cal.py` 实况计算、`gait_npz_parser.py` 回放解析及部分 UI 展示中）实际使用的变量名、机制与核心公式对比映射如下：

| 类别 (Category) | 英文参数 (English Parameter) | 学术中文翻译 | 定义说明 | 项目代码变量名 / 实现状态 | 计算公式 (基于代码变量) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **核心定义与阶段** | Gait Cycle | 步态周期 | 包含支撑相与摆动相的完整过程。 | **`stride_time`** | `stride_time = next_touch.time - touch.time` |
| | Stance Phase | 支撑相 | 足部接触地面的阶段。 | **`support_duration`** (或 `contact_duration`) | `support_duration = lift.time - touch.time` |
| | Swing Phase | 摆动相 | 足部腾空向前迈进的阶段。 | **`flight_duration`** | `flight_duration = next_touch.time - lift.time` |
| | Single Support | 单支撑期 | 仅有一侧足部接触地面的时间。 | **`single_support`** (需补充计算) | `single_support = 对侧.flight_duration` (在双足交替正常时) |
| | Double Support (DS) | 双支撑期 / 双支相 | 两侧足部同时接触地面的阶段。 | **`double_support`** (需补充计算) | `double_support = support_duration(同侧) + support_duration(对侧) - stride_time` |
| | Load Response (DS1) | 负荷反应期 | 步态周期中的第一个双支撑期。 | **`load_response`** (需补充计算) | `load_response = 对侧.lift.time - 本侧.touch.time` |
| | Pre-Swing (DS2) | 摆动前期 | 步态周期中的第二个双支撑期。 | **`pre_swing`** (需补充计算) | `pre_swing = 本侧.lift.time - 对侧.touch.time` |
| | Heelstrike | 足跟着地 / 初次触地 | 支撑相的起始点。 | **`touch_event.time`** | *读取硬件遮挡信号触发的时间戳* |
| | Toe off | 足离地 / 趾离地 | 支撑相结束、摆动相开始的临界点。 | **`lift_event.time`** | *读取硬件无遮挡信号恢复的时间戳* |
| **空间与运动学参数** | Step Length | 步长 | 一侧足着地点到另一侧足着地点之间的距离。 | **`step_length`** | `step_length = abs(本侧.centroid - 对侧.centroid)` |
| | Stride Length | 步幅 | 同一侧足连续两次着地点之间的距离。 | **`stride_length_cm`** | `stride_length_cm = abs(next_touch.centroid - touch.centroid)` |
| | Step Time | 步时间 | 一侧足着地到对侧足着地之间的时间间隔。 | **`step_time`** | `step_time = abs(本侧.touch.time - 对侧.touch.time)` |
| | Cadence | 步频 | 单位时间内的步数（通常以 steps/s 表示）。 | **`cadence_steps_per_min`** | `cadence_steps_per_min = 60.0 / (avg_stride_time_s / 2)` （假设双足对称） |
| | Speed | 速度 | 单步的平均速度。 | **`velocity_cm_s`** | `velocity_cm_s = stride_length_cm / stride_time` |
| | Accelerations | 加速度 | 前两步之间的速度变化量。 | **`acceleration`** (需补充计算) | `acceleration = (velocity_cm_s[i] - velocity_cm_s[i-1]) / stride_time[i]` |
| | TCont. (Contact Time)| 支撑时间 / 着地时间 | 足部与地面接触的持续时间。 | **`contact_duration`** | `contact_duration = lift.time - touch.time` |
| | TFlight (Flight Time)| 腾空时间 | 跑步过程中双脚均离地的时间。 | **`flight_duration`** | `flight_duration = next_touch.time - lift.time` |
| | Height | 重心高度变化 | 跳跃或跑步过程中身体重心的垂直位移。 | **`height_cm`** | `height_cm = (9.8 * flight_duration^2 / 8.0) * 100.0` (基于竖直上抛匀加速假定) |
| | Alpha | 切线角 | 步长与重心垂直摆幅构成的抛物线切线与地面的夹角。| **`alpha`** (需补充计算) | `alpha = arctan(height_cm / (stride_length_cm / 2)) * (180 / π)` |
| | Imb. (Imbalance) | 不平衡指数 | 评估左右步态对称性的指标。 | **`imbalance`** (需补充计算) | `imbalance = abs(L_val - R_val) / ((L_val + R_val) / 2) * 100%` (val 可为步长/支撑时间) |
| **支撑相细分参数** | Contact Phase | 着地相 / 初始触地期 | 从足跟着地到全足平放地面的过程。 | *(暂未实现，需高频面积测算)* | 需要定义从 `touch.time` 开始至 `遮挡比率` 达到最大平稳态的时间。 |
| | Foot Flat | 全足支撑期 / 撑地期 | 足底完全接触地面的阶段。 | *(暂未实现，需高频面积测算)* | 需要定义 `遮挡比率` 维持高位的连续持平时长。 |
| | Propulsive Phase | 推进相 / 推离期 | 从足跟离地到脚尖完全离地的过程。 | *(暂未实现，需高频面积测算)* | 需要定义从 `遮挡比率` 陡降点一直到 `lift.time` 的残余时间。 |
| **频率与压力中心参数**| FD_AP | 前后向频率离散度 | 衡量前后向（AP）功率谱频率内容的变异程度。 | *(暂未实现，需 IMU 数据)* | 根据功率谱 $p_f$: `Shannon Entropy = -Σ(p_f * log(p_f))` |
| | FD_ML | 左右向频率离散度 | 衡量中左向（ML）功率谱频率内容的变异程度。 | *(暂未实现，需 IMU 数据)* | 根据功率谱 $p_f$: `Shannon Entropy = -Σ(p_f * log(p_f))` |

### 原有核心代码分布速览：

1. **`Gait_cal.py`** 
   - 包含流式基础指标提取：`contact_duration = max(lift.time - touch.time, 0.0)`，以及步幅 `stride = abs(e2.centroid - e1.centroid)`。
2. **`gait_npz_parser.py`** 
   - 包含完整双脚指标推导：`步频cadence`、`步速velocity_cm_s`、`步长step_length` 等结合左右脚相对位置和周期时间（stride_time）的派生计算。
3. **`start_test.py` 等 UI 与前端文件** 
   - 包含基于力学时间公式推导的空间衍生量，如腾空高度 `height_cm = (9.8 * flight_duration^2 / 8.0) * 100.0`。
