### 1.1 `optojump参数汇总.md` 格式升级

### 1.2 新增：`代码步态参数汇总.md`
此文档作为衔接“理论分析”与“项目代码”的字典型桥梁构建。将每一个业务定义锚定到了具体的文件和变量名上。并严格化了各个物理公式。
重要的衍生计算和公式约束如下（节选重要字段）：
- **Cadence (步频)**: `60.0 / (avg_stride_time_s / 2)`
- **Speed (速度)**: `stride_length_cm / stride_time`
- **Height (腾空高度)**: 利用力学滞空期 `(9.8 * flight_duration^2 / 8.0) * 100.0`
- **Alpha (切线角)**: `arctan(height_cm / (stride_length_cm / 2)) * (180 / π)`
- **Imbalance (不平衡指数)**: `abs(L_val - R_val) / ((L_val + R_val) / 2) * 100%`

## 2. 引擎下钻开发：新增 `extra_parameter.py`

针对上阶未落地的空白高级步态特征（如步态各亚周期细分、对称性偏差等），单独下沉封装了一个高内聚扩展计算模块。

**重要实现机制：**
- **入口函数**: `compute_extra_parameters(cycle_data_main, cycle_data_opposite, prev_cycle_data)`。采用全解耦的字典传参设计。
- **实现的额外计算特性 (基于安全字典 Get 与物理推导)**: 
  1. `height_cm`: 竖直上抛最高点估计。
  2. `alpha_deg`: 重心最大高度与抛射着地点之间的几何切线角。
  3. `acceleration`: 本跨步速与上一个跨步速间的一阶时间微商（差分推算单步前后向加速度）。
  4. 协作分相推算：双腿依赖交集。
     - `single_support`: 映射为对侧腿飞行的耗时（`opp_flight`）。
     - `double_support`: 公式防抖设计 `(main_contact + opp_contact - main_stride_time) >= 0` 以抵御异常同步错误。
     - `imbalance_index`: `(|L-R| / mean(L, R)) * 100`。
- **Agent友好特性**: 提供纯净的返回字典，对于无前置必要信息的指标返回 `None` 且全过程防崩溃除零保护。

## 3. 业务层实装部署：前端 `2data_show.py` 埋点改造

为将提取出的高阶物理量透传至用户层，选择对 `2data_show.py` 实施最小侵入埋点改造，确保其实况界面能在获取普通触地参数之外，打印临床高阶反馈。

1. **导入拦截 (Dynamic Import Check)**: 
   为兼容不同环境调用层级（根级及目录级），引入 `import sys`, `try/except` 双重路径载入 `extra_parameter`。
2. **生命周期字典注册**: 
   在 UI Controller 核心生命始端 `_reset_analysis_state` 里注册步态流历史状态沙盒：
   `self._foot_history = {"A": {}, "B": {}}`, 并且设置缓存属性 `self._prev_cycle_data`。
3. **数据装填组装 (Data Filling at End-of-Cycle)**: 
   利用底层的 `_process_gait_clusters` 作为触发管道源：在簇分离、检测触地及确认离地 `CONFIRM_SAMPLES`（防抖完成）节点处，填入该次腿部的 `velocity`, `stride_length_cm`, `contact_duration` 数据。
4. **触发引擎与推流渲染 (Render Display Append)**:
   完成基础项拼装后，调用 `compute_extra_parameters` 推导并装载给展示区属性 `self._latest_extra_metrics`。
   在信息渲染函数 `_update_gait_display` 末尾解包输出：
   ```python
   # [ 高阶运动学特征 ]
   if em.get("alpha_deg"): -> 起跳切线角: XX°
   if em.get("imbalance_index"): -> 左右脚不平稳度: XX%
   if em.get("double_support"): -> 双支撑期耗时: XXs
   ```
