# 报告概览、明细与跑步机步幅设计规格

日期：2026-07-26

## 1. 目标

在不改变既有测试业务流程的前提下，重构测试报告的信息层级：

- 概览页根据当前测试模式优先展示最重要、且实际计算成功的指标；
- 消除概览中部大片空白和左侧卡片滚动；
- 将当前纵向堆叠的多张明细表精简为三个内部分页；
- 统一步态参数的中文名称、单位和简短解释；
- 修正跑步机步幅由“步长 × 2”近似计算的问题，使用同侧足完整步态周期及空间落点修正。

本次不重建报告以外的测试流程，不改变原始数据和 Excel 完整导出的可追溯性。

## 2. 已比较方案

### 方案 A：固定卡片集合

所有模式展示同样数量、同样类型的卡片。实现简单，但简单模式容易空旷，复杂模式又会挤掉关键指标，不符合按模式表达业务结果的要求。

### 方案 B：继续滚动并增加卡片

保留当前左侧滚动区，把缺少的指标继续加入。改动较小，但无法解决中部空白、浏览割裂和指标优先级不清的问题。

### 方案 C：按模式动态选择指标（采用）

为每种报告定义“核心结果 → 次要结果 → 上下文信息”的优先级。只展示有有效值的指标；核心结果不足时才用上下文补充。该方案能够在不同模式下同时避免拥挤和空旷。

## 3. 概览页设计

### 3.1 布局

- 左侧结果区取消 `QScrollArea`，使用三列网格平铺全部卡片。
- 1920×1080 常见窗口下展示约 9–12 张卡片，最多四行。
- 不强制凑满固定数量，也不为了填充空间展示空值。
- 右侧继续保留数据回顾/足迹回放。
- 指标区占用回放区之外的可用宽度，不在两区之间保留无意义的大块弹性空白。
- 窗口尺寸不足时优先保持内容可读，不通过新增概览纵向滚动容纳更多指标。

### 3.2 动态选择规则

每种模式维护按优先级排列的候选指标：

1. 当前模式的核心生物力学结果；
2. 当前模式的次要结果；
3. 测试上下文，顺序为有效数量、跑带速度、实际测试时长、起始脚、行进方向。

选择规则：

- 仅展示有有效值、且适用于当前模式的指标。
- 先选核心结果；指标较多时不展示低优先级上下文。
- 核心结果较少时，用上下文信息补充视觉密度。
- 最终目标是约 9–12 张卡片，而不是固定数量。
- `None`、空集合和无法形成完整周期的指标直接不显示，不显示 `--` 占位卡片。

### 3.3 跑步机步态模式优先级

核心结果：

1. 平均步长
2. 平均步幅
3. 平均步频
4. 平均步态周期
5. 平均触地时间
6. 平均支撑相
7. 平均摆动相
8. 平均双支撑时间

左右脚各至少有三个纳入统计的完整周期时，增加最有代表性的左右不对称性。剩余位置依次使用以下上下文补充：

1. 有效步数 / 检测总数
2. 跑带速度
3. 实际测试时长
4. 起始脚
5. 行进方向

腾空时间不作为步态模式的常规概览指标；如果检测到非空数据，则保留在明细和 Excel 中。

### 3.4 跑步机跑步模式优先级

核心结果：

1. 平均步长
2. 平均步幅
3. 平均步频
4. 平均步态周期
5. 平均触地时间
6. 平均腾空时间
7. 平均支撑相
8. 平均摆动相

满足样本条件时增加左右不对称性。剩余位置依次使用有效步数 / 检测总数、跑带速度、实际测试时长、起始脚和行进方向补充。

### 3.5 纵跳模式优先级

纵跳模式按以下顺序选择卡片：

1. 有效跳跃次数
2. 平均跳高
3. 最大跳高
4. 平均腾空时间
5. 平均触地时间
6. 平均跳跃节奏
7. 触地次数
8. 离地次数
9. 测试结束原因

纵跳概览不展示最小值、标准差和变异系数。单次结果和完整分布继续保留在图表、明细及 Excel 中。

### 3.6 统计口径和单位

- 所有概览平均值只使用 `is_included_in_statistics=True` 的有效步或有效完整周期。
- 自动排除无效事件、边界残段和过滤后未纳入统计的数据。
- 计数合并为 `有效数量 / 检测总数`，不再分别占用触地次数、离地次数和有效步数三张卡片。
- 步态周期使用秒（`s`）。
- 触地时间、腾空时间和双支撑时间使用毫秒（`ms`）。
- 支撑相和摆动相使用完整步态周期占比（`%`）。
- 明细和 Excel 保留原始秒数及百分比字段。

### 3.7 中文术语和提示

- `step length` 显示为“步长”：一侧足触地到对侧足随后触地之间的前进距离。
- `stride length` 显示为“步幅”，提示中补充“又称跨步长”：同侧足连续两次触地之间的前进距离。
- 指标卡通过简短 tooltip 解释定义，不在卡片正文放置长段说明。

### 3.8 不对称性最低样本

- 只有左右脚各至少有三个纳入统计的有效完整周期时，概览才展示不对称性。
- 样本不足时不显示不对称性卡片。
- 明细保留左右原始数据，并标记“样本不足，不计算不对称性”。

## 4. 跑步机步幅算法

### 4.1 当前问题

跑步机步态和跑步累加器目前将逐步结果的步幅近似为：

```text
步幅 = 当前步长 × 2
```

该近似无法反映同侧足完整周期内的落点漂移，也不满足步幅的同侧触地定义。

仅使用：

```text
带速 × 同侧步态周期时长
```

同样不完整，因为它忽略了受试者相对测试区域的前后位移。

### 4.2 采用公式

对同一侧足的两次连续有效触地，使用相同的配置参考点计算：

```text
步幅 =
    跑带速度 × 同侧两次触地时间差
    + 行进方向修正 ×（当前同侧落点参考位置 - 上一次同侧落点参考位置）
```

其中：

- `Tip-to-Tip` 比较同侧足尖位置；
- `Heel-to-Heel` 比较同侧足跟位置；
- `Interface side` 使用正方向；
- `Opposite side` 使用反方向；
- 第一条同侧触地无法形成完整周期，其步幅为 `None`；
- 未知脚、无参考点、非正时间差或无效事件不生成步幅；
- 同侧足比较不使用左右脚交替落点的 EWMA 偏置修正。

步幅在触地事件已具备同侧前序触地信息时计算，并写入对应逐步结果。统计汇总仅纳入有效且 `is_included_in_statistics=True` 的非空步幅。

### 4.3 与步态周期的关系

步幅使用的两次同侧触地边界应与完整步态周期一致。边界残段不产生步幅。概览展示所有有效左右周期步幅的总体平均值；左右脚均值分别留在明细中。

## 5. 明细页设计

明细页不再纵向堆叠多张表，改为三个内部分页，每次只显示一个主要表格。

### 5.1 统计汇总（默认）

默认列：

- 指标
- 有效样本数
- 总体均值
- 左脚均值
- 右脚均值
- 不对称性

最小值、最大值、标准差和变异系数放入“更多统计”展开区，不在默认表格中占据宽度。周期汇总、普通指标汇总和左右对比合并到该视图，不再分别生成多张表。

### 5.2 周期明细

合并现有“周期阶段图”和“周期明细”，默认显示：

- 序号
- 脚
- 周期阶段图
- 步态周期
- 支撑相
- 摆动相
- 步幅
- 纳入统计状态

表格保留“统计说明”列，用于展示排除原因和质量提示。仅在当前模式有意义且数据非空时显示扩展字段。

### 5.3 逐步数据

跑步机步态模式显示：

- 序号
- 脚
- 步长
- 触地时间
- 纳入统计状态
- 统计说明

跑步机跑步模式在上述列之间增加“腾空时间”。不适用或整列无值的指标列不创建。

参考点坐标、内部修正来源等工程字段不在普通界面中展示，但继续完整导出到 Excel。

### 5.4 数据筛选

“周期明细”和“逐步数据”顶部提供：

```text
已纳入（默认） | 已排除 | 全部
```

- 默认只显示纳入统计的数据；
- “已排除”显示排除原因；
- “全部”用于完整追溯；
- 筛选只影响界面，不改变报告数据和 Excel 导出。

## 6. 数据流和边界

1. 累加器在触地/离地事件中计算逐步指标和同侧步幅。
2. 处理器只对有效、纳入统计、数值非空的数据建立汇总。
3. 报告对象继续保存逐步结果、完整周期、左右汇总和配置快照。
4. 报告视图通过模式专用候选列表选择概览指标，不在 UI 中重新推导底层事件。
5. 三个明细分页读取同一不可变报告对象，筛选仅控制行可见性。
6. Excel 导出继续使用完整报告数据，不受 UI 精简影响。

## 7. 异常和缺失数据

- 缺少有效值：概览不创建对应卡片。
- 无完整同侧周期：不显示步幅。
- 不对称性样本不足：概览省略，汇总表显示样本不足。
- 只有被排除的数据：默认明细表为空，并允许切换到“已排除”查看原因。
- 未知脚或缺失足部参考点：不计算同侧步幅，其他可用指标照常显示。

## 8. 测试与验收

### 8.1 算法测试

- 同侧第二次触地按“跑带位移 + 同侧落点变化”计算步幅。
- `Interface side` 和 `Opposite side` 的空间修正方向正确。
- 首个同侧触地、未知脚、缺失参考点和非正周期不生成步幅。
- 跑步机步态和跑步累加器采用相同的同侧定义。
- 步幅汇总只使用纳入统计的非空结果。

### 8.2 概览测试

- 概览统计区不再使用滚动容器。
- 卡片按三列布局，数量不超过12。
- 跑步机步态优先展示已确认的核心结果。
- 跑步模式显示腾空时间；步态模式不把腾空时间作为常规概览指标。
- 空指标不生成占位卡片。
- 不对称性仅在左右各至少三个有效周期时出现。
- 有效数量使用 `有效 / 总数` 合并表达。
- 时间和相位单位符合本规格。

### 8.3 明细测试

- 明细页包含“统计汇总、周期明细、逐步数据”三个内部分页。
- 旧的多表纵向堆叠被替换，每个分页只承载其对应主表。
- 默认筛选为“已纳入”，可切换“已排除”和“全部”。
- 筛选不会改变报告数据。
- 技术字段仍存在于 Excel 导出。

### 8.4 回归验证

- 跑步机处理器、报告持久化、Excel 导出和报告视图的聚焦测试全部通过。
- 完整测试套件运行并记录任何与本次改动无关的既有失败。
- 最终差异只包含本规格、实现文件和对应测试，不修改当前工作树中的无关文件。
