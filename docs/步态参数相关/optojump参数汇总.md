# Optojump 步态分析参数学术翻译汇总

步态周期（Gait Cycle）从一侧足跟着地开始，到同一侧足跟再次着地结束 。

| 类别 (Category) | 英文参数 (English Parameter) | 学术中文翻译 (Chinese Translation) | 定义说明 (Definition) |
| --- | --- | --- | --- |
| 核心定义与阶段 | Gait Cycle | 步态周期 | 包含支撑相与摆动相的完整过程 。 |
| 核心定义与阶段 | Stance Phase | 支撑相 | 足部接触地面的阶段（通常占周期的 60%） 。 |
| 核心定义与阶段 | Swing Phase | 摆动相 | 足部腾空向前迈进的阶段（通常占周期的 40%） 。 |
| 核心定义与阶段 | Single Support | 单支撑期 | 仅有一侧足部接触地面的时间 。 |
| 核心定义与阶段 | Double Support (DS) | 双支撑期 / 双支相 | 两侧足部同时接触地面的阶段 。 |
| 核心定义与阶段 | Load Response (DS1) | 负荷反应期 | 步态周期中的第一个双支撑期 。 |
| 核心定义与阶段 | Pre-Swing (DS2) | 摆动前期 | 步态周期中的第二个双支撑期 。 |
| 核心定义与阶段 | Heelstrike | 足跟着地 / 初次触地 | 支撑相的起始点 。 |
| 核心定义与阶段 | Toe off | 足离地 / 趾离地 | 支撑相结束、摆动相开始的临界点 。 |
| 空间与运动学参数 | Step Length | 步长 | 一侧足着地点到另一侧足着地点之间的距离 。 |
| 空间与运动学参数 | Stride Length | 步幅 | 同一侧足连续两次着地点之间的距离 。 |
| 空间与运动学参数 | Step Time | 步时间 | 一侧足着地到对侧足着地之间的时间间隔 。 |
| 空间与运动学参数 | Cadence | 步频 | 单位时间内的步数（通常以 steps/s 表示） 。 |
| 空间与运动学参数 | Speed | 速度 | 单步的平均速度 。 |
| 空间与运动学参数 | Accelerations | 加速度 | 前两步之间的速度变化量 。 |
| 空间与运动学参数 | TCont. (Contact Time) | 支撑时间 / 着地时间 | 足部与地面接触的持续时间 。 |
| 空间与运动学参数 | TFlight (Flight Time) | 腾空时间 | 跑步过程中双脚均离地的时间 。 |
| 空间与运动学参数 | Height | 重心高度变化 | 跳跃或跑步过程中身体重心的垂直位移 。 |
| 空间与运动学参数 | Alpha | 切线角 | 步长与重心垂直摆幅构成的抛物线切线与地面的夹角 。 |
| 空间与运动学参数 | Imb. (Imbalance) | 不平衡指数 | 评估左右步态对称性的指标 。 |
| 支撑相细分参数 | Contact Phase | 着地相 / 初始触地期 | 从足跟着地到全足平放地面的过程 。 |
| 支撑相细分参数 | Foot Flat | 全足支撑期 / 撑地期 | 足底完全接触地面的阶段 。 |
| 支撑相细分参数 | Propulsive Phase | 推进相 / 推离期 | 从足跟离地到脚尖完全离地的过程 。 |
| 频率与压力中心参数 | FD_AP (AP Frequency Dispersion) | 前后向频率离散度 | 衡量前后向（Antero-posterior）功率谱频率内容的变异程度（0-1） 。 |
| 频率与压力中心参数 | FD_ML (ML Frequency Dispersion) | 左右向频率离散度 | 衡量中左向（Medio-lateral）功率谱频率内容的变异程度（0-1） 。 |

*注：空间与运动学参数主要出现在 Run Data（跑步数据）和 Gait Data（步态数据）列中。支撑相细分参数由 Optojump 对支撑过程进行精细化时间切分（以秒 [s] 或百分比 [%] 表示）。频率与压力中心参数在结合 Gyko 惯性传感器使用时出现进行频域分析。*

## 当前项目实现口径补充（demo）
- Cadence（步频）当前在“步态分析模式”中采用触地事件间隔近似计算：  
  `平均步频 = 60 / 平均步间隔`（单位：步/分钟）。
- 该值在“分析结束汇总”中展示，不做实时展示。
