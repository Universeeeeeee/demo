# OptoJump 步态周期与相位说明

本文说明 OptoJump 中常见的步态周期、支撑相、摆动相和足底接触阶段，帮助读者正确理解测试结果。内容已依据《OptoJump Next User Manual》1.12.1 版核验。

## 先看结论

- 一个步态周期（Gait Cycle）是同一只脚从一次触地到下一次触地的完整过程，由支撑相和摆动相组成。
- 单支撑和双支撑描述的是两只脚之间的关系，必须结合左右脚事件判断，不能只看单脚的接触时间。
- Contact Phase、Foot Flat 和 Propulsive Phase 是一次足部接触内部的三个阶段，不是完整步态周期的三个阶段。
- OptoJump 的跑步/步态类测试会提供 Run Data 和 Gait Data 两个结果页；跑步测试还可提供 Run Report。
- 软件显示某个字段，不代表对应的生理阶段一定发生。例如，典型跑步通常有腾空期而没有双支撑期。

## 1. 一个步态周期如何划分

以右脚为例，一个周期从右脚首次触地开始，到右脚下一次触地结束：

```text
右脚触地                 右脚离地                    右脚再次触地
   │                        │                           │
   ├────── 支撑相 Stance ───┤────── 摆动相 Swing ──────┤
   └──────────────── 一个步态周期 Gait Cycle ───────────┘
```

说明书以正常步行为例，给出约 60% 支撑相、40% 摆动相的典型比例。这只是帮助理解的参考值，不是判断正常或异常的固定阈值。

### 支撑相（Stance Phase）

同一只脚从首次接触地面到完全离地的时间。按照说明书采用的典型足跟—足尖接触顺序，也就是从足跟触地到足尖离地：

```text
支撑时间 = 本次离地时刻 - 本次触地时刻
```

OptoJump 可同时用秒和该侧步态周期的百分比表示支撑相。

### 摆动相（Swing Phase）

同一只脚从完全离地到下一次触地的时间：

```text
摆动时间 = 下次同侧触地时刻 - 本次离地时刻
```

OptoJump 可同时用秒和该侧步态周期的百分比表示摆动相。

因此，在事件完整且配对正确时：

```text
步态周期时间 = 支撑时间 + 摆动时间
```

> 注意：说明书使用“足跟触地”和“足尖离地”描述典型步态。前足着地、拖步或其他非典型接触模式不一定符合这个足跟—全足—足尖的顺序，此时相关阶段仍可由光栅事件计算，但解读要更谨慎。

## 2. 单支撑与双支撑

### 单支撑（Single Support）

单支撑是只有一只脚接触地面的时间。以右脚为统计侧时，右脚单支撑发生在左脚摆动期间，因此：

```text
右脚单支撑时间 = 左脚摆动时间
左脚单支撑时间 = 右脚摆动时间
```

这项指标依赖可靠的左右脚标签和跨侧事件关联。

### 双支撑（Double Support）

双支撑是双脚同时接触地面的时间。典型步行的一个周期内有两段双支撑：

```text
本侧触地       对侧离地          对侧触地       本侧离地
   │               │                 │              │
   ├─ DS1 ─────────┤                 │              │
   │  Load Response                  │              │
   │               ├─ 单支撑 ────────┤              │
   │                                 ├─ DS2 ────────┤
   │                                    Pre-Swing
```

- DS1 / Load Response：第一次双支撑，也称负荷反应期。
- DS2 / Pre-Swing：第二次双支撑，也称摆动前期。
- Total Double Support：两段双支撑之和。

```text
总双支撑时间 = DS1 + DS2
```

该关系适用于能够明确区分两段双支撑的情况。如果双脚持续重叠、无法可靠划分第一次和第二次双支撑，应保留总双支撑时间，并将负荷反应期和摆动前期显示为 `N/A`，避免重复计算同一段重叠时间。

“一个周期有两段双支撑”描述的是典型步行模型，不应机械套用到跑步。若左右脚接触区间没有重叠，就没有双支撑。

## 3. Step Time 与 Gait Cycle 不同

两者都以触地事件为边界，但终点不同：

| 指标 | 起点 | 终点 | 含义 |
| --- | --- | --- | --- |
| Step Time（步时间） | 一只脚首次触地 | 对侧脚首次触地 | 跨侧相邻两步的时间 |
| Gait Cycle（步态周期） | 一只脚首次触地 | 同一只脚下一次首次触地 | 同侧一个完整周期的时间 |

```text
步时间 = 对侧脚首次触地时刻 - 当前脚首次触地时刻
步态周期 = 下次同侧首次触地时刻 - 当前脚首次触地时刻
```

## 4. 一次足部接触内部的三个阶段

下面三个阶段只描述支撑相内部的足底接触变化：

```text
首次触地          全足支撑           足跟抬起          足尖完全离地
   │                 │                  │                  │
   ├─ Contact Phase ─┤──── Foot Flat ───┤─ Propulsive Phase ┤
   └──────────────────── 总接触时间 ───────────────────────┘
```

| OptoJump 字段 | 推荐中文 | 说明 |
| --- | --- | --- |
| Contact Phase | 着地相 | 从足跟首次接触到足部形成完整支撑 |
| Foot Flat | 全足支撑期 | 足部完整接触地面的持续时间 |
| Propulsive Phase | 推进相 | 从足跟抬起到足尖完全离地 |

这三个字段在 Run Data 和 Gait Data 中都会出现。它们的百分比均以本次总接触时间为分母：

```text
阶段百分比 = 阶段时间 ÷ 本次总接触时间 × 100%
```

不要用整个步态周期作为分母。

## 5. Run Data、Gait Data 与 Run Report

说明书将普通地面和跑步机上的 Sprint/Gait 类测试结果分为两个数值页：

| 结果页 | 主要用途 | 与相位有关的典型字段 |
| --- | --- | --- |
| Run Data | 查看逐步的跑动、接触和空间结果 | Contact Time、Flight Time、Double Support、Step Time，以及三个足底接触阶段 |
| Gait Data | 查看完整步态周期及左右脚配合 | Stance、Swing、Single Support、Total Double Support、Load Response、Pre-Swing、Gait Cycle，以及三个足底接触阶段 |
| Run Report | 查看跑步中的左右脚不对称 | 仅 Run Test 提供；适用于模块化地面系统和跑步机 |

这里需要区分两件事：

1. **字段是否由软件提供**：说明书明确列出了上述结果页和字段。
2. **阶段是否在本次运动中实际发生**：要由真实的触地、离地和双脚重叠关系判断。

例如，Double Support 出现在说明书的结果列中，但典型跑步若存在双脚腾空、没有左右脚接触重叠，则本次双支撑时间应为 0，而不是因为界面有该列就解释出一段双支撑。

## 6. 不同测试模式如何使用这些概念

| 测试类型 | 建议解读 |
| --- | --- |
| 普通地面 Gait Test | 可使用完整的步态周期、单双支撑和足底接触阶段 |
| 普通地面 Sprint / Run Test | 可查看 Run Data、Gait Data 和 Run Report；双支撑相关指标须按实际接触重叠解释 |
| Treadmill Gait Test | 可使用完整的步态周期、单双支撑和足底接触阶段 |
| Treadmill Running Test | 可查看 Run Data、Gait Data 和 Run Report；双支撑相关指标须按实际接触重叠解释 |
| Tapping Test | 主要查看左右脚 Contact、Flight、Rhythm 等结果，不使用本文的完整步态周期相位体系 |
| Jump / Reaction Test | 主要查看接触、腾空、跳高或反应时间，不使用本文的完整步态周期相位体系 |
| Static / Sway、Vertec Like | 分别属于姿态摆动或摸高分析，不使用本文的步态相位体系 |
| Jump + Gyko | 可出现 Eccentric、Concentric 等跳跃动力学阶段，但它们不是步态周期相位 |

## 7. 结果中 0 与 N/A 的区别

| 显示值 | 应表达的含义 | 示例 |
| --- | --- | --- |
| `0` | 已有足够数据完成计算，结果确实为零 | 左右脚接触区间没有重叠，双支撑时间为 0 |
| `N/A` / `None` | 当前模式不适用，或数据不足以可靠计算 | 左右脚标签缺失，无法计算单支撑 |

不要用 0 掩盖缺失数据，也不要把 N/A 解读为“实际没有发生”。

## 8. 解读时最容易混淆的三点

1. **Flight Time 不是 Swing Time。** Flight Time 是双脚都不接触地面的时间；Swing Time 是某一只脚从离地到该脚下次触地的时间。走路通常有摆动相，但没有腾空期。
2. **单脚接触时间不能直接得到单双支撑。** 单支撑和双支撑都需要左右脚事件的时间关系。
3. **普通光栅数据不能替代 Gyko。** Eccentric、Concentric、Force、Power 等指标需要 Gyko 或其他相应传感能力，不能只根据 LED 遮挡事件推导。

## 9. 数据核验规则（供实现与验收）

在事件完整、左右脚映射与跨侧事件关联正确的前提下，可用以下关系检查结果是否自洽：

```text
支撑时间 + 摆动时间 ≈ 同侧步态周期时间
本侧单支撑时间 ≈ 对侧摆动时间
能够区分两段双支撑时：总双支撑时间 ≈ Load Response + Pre-Swing
足底接触阶段百分比的分母 = 本次总接触时间
```

计算单双支撑至少需要每次触地、每次离地、可靠的左右脚标签及接触区间。数据不足时应返回 N/A，而不是推测或补造结果。
