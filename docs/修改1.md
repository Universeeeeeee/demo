# 修补目标

只修复以下问题：

1. 静止不动时，不应产生 touch / lift 幻觉事件
2. 启动后已有残余遮挡/噪声簇时，不应被当成第一步
3. 候选 contact 不能因为“活得够久”就自动变成 touch
4. 修复 `_foot_lift_time` 未初始化的显式 bug

# 必须执行的修改

## 1. 增加 gait armed 机制

在系统开始分析后，只有经历过一段稳定“无接触”状态，才允许后续 candidate 被确认为 touch。

### 在 `__init__()` 和 `_reset_analysis_state()` 中新增并初始化以下字段：

```python
self._gait_armed = False
self._no_contact_stable_frames = 0
self._arm_frames = 10
self._foot_lift_time = {"A": None, "B": None}
```

说明：

* `_gait_armed`：系统是否进入可触发步态事件状态
* `_no_contact_stable_frames`：连续无接触帧计数
* `_arm_frames`：多少帧无接触后进入 armed
* `_foot_lift_time`：修复当前代码里被使用但未初始化的问题

---

## 2. 在 `_process_gait_clusters()` 里加入 armed 更新逻辑

在拿到 `active_tracks` 后，加入：

* 如果当前没有 active tracks，则 `_no_contact_stable_frames += 1`
* 否则 `_no_contact_stable_frames = 0`
* 当 `_no_contact_stable_frames >= _arm_frames` 时，置 `_gait_armed = True`

注意：

* 这里的“无接触”以 `gait_tracker` 当前 active tracks 为空为准
* 不要因为出现 candidate 就自动 armed
* armed 一旦为 True，可保持 True，不需要反复关闭

建议放在 `_process_gait_clusters()` 前半段，位于 contact 更新逻辑之前或之后都可以，但必须在 `_confirm_new_contacts()` 前完成。

---

## 3. 修改 `_confirm_new_contacts()`：未 armed 时禁止 touch

在 candidate 确认逻辑里加入第一道门：

```python
if not self._gait_armed:
    continue
```

含义：

* 系统未经历过稳定无接触基线前，任何 candidate 都不能转为 confirmed touch

---

## 4. 修改 `_confirm_new_contacts()`：增加“新生窗口”限制

当前最大问题是：candidate 只要连续出现几帧，且时间超过最小步间隔，就会被确认。
这会把“背景持续存在”误当成“新触地”。

必须增加一条规则：

* 只有“刚刚新出现”的 candidate，才允许被确认为 touch
* 如果一个 candidate 存在太久才想确认，说明它不是触地边沿，而更像静态占用或噪声

请加入：

```python
contact_age = timestamp - contact.first_seen_time
if contact_age > 0.2:
    continue
```

其中 `0.2` 秒可写成局部常量，例如：

```python
max_onset_window = 0.2
```

要求：

* 只有在 `first_seen_time` 之后短时间内完成确认，才算真正 touch
* 太老的 candidate 不得转 confirmed

---

## 5. 修改 `_confirm_new_contacts()`：增加几何门槛，过滤噪声簇

除了 `seen_count >= confirm_frames`，还必须至少加两个过滤条件：

### 条件 A：簇长度下限

如果当前 contact 的 `latest_cluster_length` 太小，不允许确认为 touch。

建议：

```python
if contact.latest_cluster_length is None or contact.latest_cluster_length < 8.0:
    continue
```

### 条件 B：短窗质心抖动过滤

如果最近几帧质心波动太大，说明更像噪声，不允许确认为 touch。

建议：

```python
if len(contact.centroid_history) >= 3:
    recent = contact.centroid_history[-3:]
    jitter = max(recent) - min(recent)
    if jitter > 4.0:
        continue
```

要求：

* 这是最小修补，不要引入复杂模型
* 只做简单几何稳定性过滤即可

---

## 6. 保持 lift 只对 confirmed contact 生效

检查 `_finalize_lost_contacts()` / `_handle_lift_event()`，确保：
