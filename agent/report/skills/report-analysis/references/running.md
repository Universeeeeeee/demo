# Treadmill Running Analysis Prior

Use temporal, side, phase, and aligned metric structure to propose hypotheses; do not
run every available analysis method.

Potentially informative relationships include contact and flight timing, step or
stride length, cadence, and side-specific segment changes. Verify only relationships
for which both metrics or dimensions contain usable observations. A constant metric
does not justify a co-change test merely because it is biomechanically related to a
varying metric.

Separate the observed pattern from its interpretation. A late-session change may be
described after deterministic verification, but it must not automatically be labelled
fatigue, compensation, performance decline, injury risk, or a training requirement.
