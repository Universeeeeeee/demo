# Jump Analysis Prior

Use temporal structure and included/excluded record status to propose hypotheses. The
current jump report has no left/right dimension, so do not invent a side hypothesis.

Prefer a temporal hypothesis when a populated metric shows a coherent early-to-late
change. Treat an isolated excursion as a candidate transient pattern, not as proof of
a sustained trend. Use exclusion robustness only when records are actually excluded
and a prior Evidence item supports a temporal pattern.

Only test cross-metric co-change when both aligned metrics visibly vary. Do not pair a
varying contact metric with a constant air-time, height, cadence, or cycle metric just
to consume another analysis action.

Do not translate a verified session pattern into neuromuscular fatigue, readiness,
injury risk, diagnosis, or training advice without separately authorized evidence.
