# Treadmill Gait Analysis Prior

Use side, time, segment, and aligned metric structure to propose hypotheses; do not
treat this list as a checklist.

Prefer hypotheses that distinguish among:

- a whole-session temporal change;
- a change concentrated on one side or one segment;
- two metrics changing together in aligned records;
- an apparent pattern that depends on excluded records.

When both sides are available, ask whether an overall change is actually concentrated
on one side. When an overall mean appears stable, inspect whether opposing side or
segment changes could mask one another. Choose cross-metric verification only when
both metrics contain a visible candidate change.

Describe verified output as a session pattern. Do not interpret asymmetry as pathology,
fatigue, injury risk, or a treatment need.
